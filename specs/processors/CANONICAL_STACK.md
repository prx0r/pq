## Why Processors are not a tenth constitutional owner

Processors are a **package layer**, analogous to standard-library procedures.

They do not own canonical state.

AgentCom selects/assembles them.

A-Task bounds their work.

OpenAI/other drivers execute them.

QP validates resulting claims/consequences.

CG evaluates alternative processor implementations.

Seed0 searches/mutates processor graphs.

Therefore the hard ownership table remains stable.

## Canonical flow

```text
technical spec
  -> MissionSpec
  -> ActualityContract / ContractRoot
  -> unresolved QP proof leaves
  -> retrieve similar verified runs
  -> assemble candidate ProcessorGraph
  -> generate 5 Seed0 lanes
  -> execute through OpenAI Agents or another driver
  -> probes / artifacts / effects
  -> QP settlement
  -> only QP-valid Actuality-complete lanes rank
  -> store verified trajectories
  -> mutate/explore again next time
```
